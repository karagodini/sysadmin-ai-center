# AI Agent Panel

Инструкция по развертыванию и использованию панели на вашем сервере.

## Требования
- Ubuntu / Linux сервер
- Python 3.10+
- Git

---

## 1. Клонирование репозитория
Клонируйте проект на ваш сервер:
```bash
git clone https://github.com/ВАШ_ПОЛЬЗОВАТЕЛЬ/ВАШ_РЕПОЗИТОРИЙ.git
cd ai-agent
```

## 2. Настройка окружения (.env)
Создайте файл `.env` в корне проекта:
```bash
nano .env
```
Добавьте туда необходимые параметры (например, API-ключи):
```env
OPENAI_API_KEY=your_api_key_here
# Добавьте другие переменные при необходимости
```

## 3. Установка зависимостей
Рекомендуется использовать виртуальное окружение:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## 4. Запуск приложения
Запустите Streamlit приложение:
```bash
streamlit run app.py --server.port 8501 --server.address 0.0.0.0
```

---

## Правила разработки (Workflow)
1. Все изменения создаются в отдельной ветке (`git checkout -b feature/name`).
2. Код коммитится и пушится на GitHub.
3. Проверяется работоспособность.
4. Только после успешной проверки выполняется merge в `main` и обновление продакшна.

### Как получить API-ключ Gemini:
1. Перейдите на официальный сайт [Google AI Studio](https://aistudio.google.com/).
2. Войдите под своим аккаунтом Google.
3. Нажмите кнопку **"Get API key"** (Получить ключ API).
4. Создайте новый ключ в существующем или новом проекте Google Cloud.
5. Скопируйте полученный ключ и вставьте его в файл `.env` в параметр `GEMINI_API_KEY`:
   ```env
   GEMINI_API_KEY=ваш_скопированный_ключ_сюда
   ```
